Regras de meta:
Exemplo:
Meta mensal = R$ 10.000
Meta semanal = R$ 2.500

Se usuário escolhe 2 dias de folga por semana:
2 x 4 = 8 dias de folga estimados no mês
Se mês tem 31 dias:
31 - 8 = 23 dias úteis de meta

Meta diária:
10.000 / 23 = meta diária base

Se em um dia a meta era R$ 500 e o usuário fez R$ 400:
Diferença = R$ 100
Essa diferença deve ser redistribuída nos dias restantes do mês

Se o usuário fizer acima da meta:
Excedente pode reduzir a meta dos dias restantes

Essas regras ficam em:
engines/meta-engine.ts

Tela não calcula meta.

CUSTO FIXO
========================

Ponto muito importante do app.

Custos fixos iniciais:

- Aluguel do veículo

- Manutenções básicas, se ativado

Criar tela:
Despesas Fixas

Objetivo:
Mostrar quanto o motorista precisa pagar por dia só para manter o carro e o trabalho funcionando.

A tela deve mostrar:
- custo fixo mensal
- custo fixo diário
- custo fixo por jornada
- custo fixo acumulado no mês
- custo fixo restante até fim do mês
- custos ativos e inativos

Regras:
- Nada disso é calculado na tela
- Tudo no despesa-fixa-engine.ts

IPVA:
- Considerar UF do carro
- Considerar valor FIPE
- Considerar tipo de tração: flex, elétrico, híbrido, gnv
- Criar estrutura para tabela de alíquotas por estado
- Alguns estados podem ter isenção/redução para elétrico/híbrido
- Deixar tabela preparada para alíquota, isenção e observação

Criar tabela:
ipva_aliquotas

Campos:
- id
- uf
- tipo_veiculo
- tipo_tracao
- aliquota
- tem_isencao
- percentual_reducao
- observacao
- created_at
- updated_at

Cálculo IPVA:
valor_ipva = valor_fipe * aliquota

Resultado SOMA integral:
- Considera período de 1º de janeiro a 31 de dezembro
- Divide o valor anual por 365 dias
- Mostra custo diário integral

IPVA SOMA parcial:
- Considera a data do primeiro lançamento de jornada
- Vai da data do primeiro lançamento até 31 de dezembro
- Divide proporcionalmente pelo número de dias restantes
- Mostra custo diário parcial

Seguro:
- Se anual:
  dividir valor pelo período do seguro
- Se mensal:
  dividir valor mensal por dias do mês
- Também mostrar visão integral e parcial

Aluguel:
- Se semanal:
  equivalência mensal = valor semanal x 4
- Se quinzenal:
  equivalência mensal = valor quinzenal x 2
- Se mensal:
  equivalência mensal = valor mensal
- Calcular custo diário
- Se usuário não trabalhar em um dia, o custo daquele dia não desaparece
- O custo deve ser diluído nos dias restantes

Financiamento:
- Usar valor da parcela
- Vencimento
- Data fim contrato
- Calcular custo mensal e diário

Depreciação:
- Criar regra inicial simples:
  permitir percentual mensal ou anual configurável
- Usar valor FIPE como base
- Exemplo:
  depreciacao_mensal = valor_fipe * percentual
- Deixar motor preparado para evoluir depois

Internet:
- Valor mensal configurável
- Custo diário = valor mensal / dias do mês

Custo SOMA:
- Começa desligado
- Se ativado, usar valor do plano como custo fixo
- Mensal/semestral/anual deve ser convertido em custo diário

Manutenções básicas:
- Se ativado, usar manutencao-engine para estimar custo proporcional por km ou tempo

Regra importante:
O número de dias restantes nunca pode ignorar dia não trabalhado.

Exemplo:
Restam 300 dias.
Usuário não trabalha hoje.
O custo fixo de hoje deve ser redistribuído nos próximos dias.

========================
REGRAS FINAIS
========================

- Não usar dados mockados
- Não colocar lógica em tela
- Não permitir CPF inválido
- Não permitir CPF duplicado
- Não salvar CPF/telefone com máscara
- CPF só salva uma vez
- Todos os dados persistem no Supabase
- Botões de salvar só funcionam com onboard completo
- Criar telas de editar e apagar para jornadas, ganhos, despesas, abastecimentos e manutenções
- Código limpo, organizado e escalável
- TypeScript bem tipado
- Criar engines para cálculos
- Criar hooks para orquestração
- Criar services para Supabase
- Criar componentes reutilizáveis para calendário e gráficos
- Preparar arquitetura para ranking futuro, mas não implementar ranking agora
- Preparar arquitetura para jornada automática futura, mas não implementar GPS agora
